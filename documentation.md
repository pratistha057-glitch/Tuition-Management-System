# Tuition Management System

## Development Environment

The project is developed using:

- Visual Studio Code
- Python
- Django
- Django REST Framework
- uv for Python package and project management
- Git for version control
- GitHub for remote repository management

## Project Structure

The project is divided between two developers.

### Person 1
- Accounts
- Students
- Courses

### Person 2
- Attendance
- Fees
- Payments
- Core/Dashboard
